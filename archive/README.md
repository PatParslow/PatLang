# Archive

This directory holds documentation from an earlier, since-abandoned
implementation approach (a Ruby reference interpreter plus a separate C
runtime prototype). It predates and is unrelated to the current, working
PatLang system: the self-hosted compiler in `self_hosting/`, running on the
Rust VM in `rust-runtime/`.

Kept for historical reference only. For current documentation, see
[`TUTORIAL.md`](../TUTORIAL.md) and
[`PATLANG_SELF_HOSTING_ROADMAP.md`](../PATLANG_SELF_HOSTING_ROADMAP.md) at
the repository root.
