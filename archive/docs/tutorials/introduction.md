# Introduction to Patlang

Patlang is a multi-paradigm programming language designed to support imperative, object-oriented, goal-oriented, logic, functional, and event-driven programming styles. Its flexible syntax and runtime allow developers to choose the most effective paradigm for each problem, or to combine them for advanced solutions.

## Why Patlang?

Patlang was created to bridge the gap between different programming paradigms, allowing developers to use the best tool for each job. Whether you prefer the clarity of imperative code, the structure of OOP, the expressiveness of logic programming, or the power of functional and event-driven styles, Patlang lets you mix and match as needed.

## Key Features

- **Multi-paradigm:** Use imperative, OOP, logic, functional, event-driven, and goal-oriented styles.
- **Flexible Syntax:** Write code that feels natural for each paradigm.
- **Extensible:** Add new paradigms or features as the language evolves.
- **Interoperable:** Integrate with other languages and systems.

## Running Patlang Programs

To run a Patlang program, use the Patlang CLI or interpreter:

```sh
patlang run your_program.patlang
```

Replace `your_program.patlang` with your source file. The CLI supports additional options for debugging, module management, and interactive sessions.

### Example CLI Usage

```sh
patlang run hello_world.patlang
patlang repl
patlang run --debug complex_project.patlang
```

## Supported Paradigms

- **Imperative:** Variables, statements, and control flow.
- **Object-Oriented:** Classes, objects, encapsulation, and (if supported) inheritance.
- **Goal-Oriented:** Define goals and let the system resolve them.
- **Logic:** Facts, rules, and queries for knowledge-based programming.
- **Functional:** First-class functions, immutability, and recursion.
- **Event-Driven:** Events, handlers, and event loops.
- **Combinations:** Mix paradigms for complex, maintainable solutions.

## Getting Started

1. Install Patlang from the official repository or package manager.
2. Write your first program in a `.patlang` file.
3. Run it using the CLI as shown above.
4. Explore the tutorials for each paradigm in this series.
