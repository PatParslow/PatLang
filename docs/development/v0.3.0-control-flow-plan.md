# Patlang v0.3.0: Control Flow Structures - Implementation Plan

## Overview

**Version**: v0.3.0  
**Focus**: Control Flow Structures  
**Strategic Priority**: Critical Blocker #1 for Self-Hosting  
**Timeline**: 3-4 weeks  
**Dependencies**: v0.2.0 Variables and Assignment (COMPLETE)  

## Strategic Context

Control flow structures are identified as the **#1 Critical Blocker** in the self-hosting gap analysis. Without conditional statements and loops, we cannot implement:
- Parser state machines with conditional logic
- Lexer character processing loops
- Error handling and recovery logic
- Complex evaluation patterns

This makes v0.3.0 absolutely essential for progressing toward self-hosting capability.

## Scope Definition

### Core Features to Implement

#### 1. Boolean Values and Logic
- Boolean literals: `true`, `false`
- Boolean variables and assignment
- Boolean expressions in conditions

#### 2. Comparison Operators
- Equality: `==`, `!=`

- Mixed type comparisons (numbers vs booleans)

#### 3. Conditional Statements
- `if` statements with single condition
- `if/else` statements
- Nested `if` statements
- Conditional expressions

#### 4. Basic Loops
- `while` loops with condition
- Loop control flow
- Break conditions

#### 5. Block Statements
- Multi-statement blocks with `{` `}`
- Proper scoping within blocks
- Statement sequencing

#### 1.2 New AST Node Types
Add to [`src/ast_nodes.rb`](src/ast_nodes.rb:1):

```ruby
# Boolean literal node
class BooleanNode < ASTNode
  attr_reader :value
  
  def initialize(value)
    @value = value
  end
  
  def to_s
    "BooleanNode(#{@value})"
  end
end

# Comparison operation node
class ComparisonNode < ASTNode
  attr_reader :left, :operator, :right
  
  def initialize(left, operator, right)
    @left = left
    @operator = operator
    @right = right
  end
  
  def to_s
    "ComparisonNode(#{@left}, #{@operator}, #{@right})"
  end
end

# Conditional statement node
class IfNode < ASTNode
  attr_reader :condition, :then_branch, :else_branch
  
  def initialize(condition, then_branch, else_branch = nil)
    @condition = condition
    @then_branch = then_branch
    @else_branch = else_branch
  end
  
  def to_s
    "IfNode(#{@condition}, #{@then_branch}, #{@else_branch})"
  end
end

# While loop node
class WhileNode < ASTNode
  attr_reader :condition, :body
  
  def initialize(condition, body)
    @condition = condition
    @body = body
  end
  
  def to_s
    "WhileNode(#{@condition}, #{@body})"
  end
end

# Block statement node (sequence of statements)
class BlockNode < ASTNode
  attr_reader :statements
  
  def initialize(statements)
    @statements = statements
  end
  
  def to_s
    "BlockNode([#{@statements.map(&:to_s).join(', ')}])"
  end
end
```

### Phase 3: Parser Grammar Extensions (Week 2)

#### 3.1 Grammar Rules
Extend [`src/parser.rb`](src/parser.rb:1) with new productions:

```
program → statement_list
statement_list → statement (NEWLINE statement)*
statement → assignment | if_statement | while_statement | expression

if_statement → IF comparison THEN statement_list (ELSE statement_list)? END
while_statement → WHILE comparison DO statement_list END

comparison → expression comparison_op expression
comparison_op → EQUAL | NOT_EQUAL | LESS_THAN | GREATER_THAN | LESS_EQUAL | GREATER_EQUAL

expression → term ((PLUS | MINUS) term)*
term → factor ((MULTIPLY | DIVIDE) factor)*
factor → NUMBER | BOOLEAN | IDENTIFIER | LPAREN expression RPAREN
```

#### 3.2 Parser Methods
- `parse_statement()` - Top-level statement parsing
- `parse_if_statement()` - Conditional statement parsing
- `parse_while_statement()` - Loop statement parsing
- `parse_comparison()` - Comparison expression parsing
- `parse_statement_list()` - Block statement parsing

### Phase 4: Evaluator Logic (Week 2-3)

#### 4.1 Node Evaluation
Extend [`src/evaluator.rb`](src/evaluator.rb:9) with new `visit_*` methods:

```ruby
def visit_boolean_node(node)
  node.value
end

def visit_comparison_node(node)
  left_value = evaluate(node.left)
  right_value = evaluate(node.right)
  
  case node.operator
  when '=='
    left_value == right_value
  when '!='
    left_value != right_value
  when '<'
    left_value < right_value
  when '>'
    left_value > right_value
  when '<='
    left_value <= right_value
  when '>='
    left_value >= right_value
  else
    raise "Unknown comparison operator: #{node.operator}"
  end
end

def visit_if_node(node)
  condition_value = evaluate(node.condition)
  
  # Convert to boolean (truthy/falsy semantics)
  if is_truthy(condition_value)
    evaluate(node.then_branch)
  elsif node.else_branch
    evaluate(node.else_branch)
  else
    nil
  end
end

def visit_while_node(node)
  result = nil
  
  while is_truthy(evaluate(node.condition))
    result = evaluate(node.body)
  end
  
  result
end

def visit_block_node(node)
  result = nil
  
  node.statements.each do |statement|
    result = evaluate(statement)
  end
  
  result
end

private

def is_truthy(value)
  # Ruby-like truthiness: false and nil are falsy, everything else is truthy
  value != false && !value.nil?
end
```

## Risk Assessment

### High Risk Areas
1. **Parser Complexity**: Control flow significantly increases grammar complexity
2. **Error Recovery**: Malformed control flow can be hard to diagnose
3. **Performance**: Loops could expose performance bottlenecks
4. **Scope Management**: Variable scoping in blocks needs careful design

### Mitigation Strategies
1. **Incremental Testing**: Test each component thoroughly before integration
2. **Clear Error Messages**: Invest in high-quality error reporting
3. **Performance Monitoring**: Benchmark loop performance early
4. **Simple Scoping**: Start with simple block scoping, enhance later
