## Technical Scope Defined

### Core Features (Implementation Ready)
- **Boolean Values**: `true`, `false` literals and variables
- **Comparison Operators**: `==`, `!=`, `<`, `>`, `<=`, `>=`
- **Conditional Statements**: `if`/`then`/`else`/`end` with nesting
- **While Loops**: `while`/`do`/`end` with proper termination
- **Block Statements**: Multi-statement sequences with scoping

### Implementation Architecture
- **17 New Tokens**: Boolean, comparison, control flow keywords
- **5 New AST Nodes**: BooleanNode, ComparisonNode, IfNode, WhileNode, BlockNode  
- **Parser Extensions**: 5 new production rules and methods
- **Evaluator Logic**: Conditional execution, loop control, truthiness evaluation
- **Testing Strategy**: 50+ tests across 5 specialized test suites
