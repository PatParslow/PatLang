   - **Root Cause**: [`Parser#primary`](src/parser.rb:532) method lacks unary operator handling
   - **Impact**: Cannot parse negative numbers or unary expressions

   - **Error**: `Unexpected token in factor at token Token(LBRACKET, [)`
   - **Root Cause**: [`Parser#postfix`](src/parser.rb:490) method missing bracket handling in actual implementation
   - **Impact**: Cannot access string characters by index
