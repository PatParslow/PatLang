The compiler, measured on itself

The self-hosted compiler front+middle end processing its own complete source (589332 chars), run under the Stage 0 interpreter while building this page:

  • tokenize: 83704 tokens in 15110 ms
  • parse: 145 top-level statements in 522 ms
  • lower: 143 functions in 457 ms
  • codegen: 2930697 chars of Rust in 495 ms

The natively compiled compiler (patc1) runs the same front end roughly two orders of magnitude faster; rustc then dominates end-to-end compile time.
