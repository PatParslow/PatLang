The compiler, measured on itself

The self-hosted compiler front+middle end processing its own complete source (381990 chars), run under the Stage 0 interpreter while building this page:

  • tokenize: 62520 tokens in 8901 ms
  • parse: 119 top-level statements in 2091 ms
  • lower: 117 functions in 20033 ms
  • codegen: 1922171 chars of Rust in 10952 ms

The natively compiled compiler (patc1) runs the same front end roughly two orders of magnitude faster; rustc then dominates end-to-end compile time.
