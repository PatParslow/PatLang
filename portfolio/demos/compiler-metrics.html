The compiler, measured on itself

v2, the compiler, building itself (self_hosting/v2/compile.patlang and its runtime) while this page was built, with its cache of compiled functions warm, as it is after any small change. The phases are its own: the front end (reading, parsing and lowering every source), the keys that name each function's compiled artefact, the jobs that build the artefacts not already stored, and the link:

  • front end 15136 ms
  • compiler key 604 ms
  • keys 3530 ms
  • jobs 125073 ms
  • jobs: reading or generating code 65506 ms
  • jobs: assembling 643000 ms
  • jobs: storing 25816 ms
  • link 24914 ms
  • in all, 222296 ms

Every phase, the code generator and the linker included, is written in PatLang; the executable it writes is the compiler that wrote it, byte for byte.
