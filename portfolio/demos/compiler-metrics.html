The compiler, measured on itself

The self-hosted compiler front+middle end processing its own complete source (483136 chars), run under the Stage 0 interpreter while building this page:

  • tokenize: 72335 tokens in 17879 ms
  • parse: 140 top-level statements in 1245 ms
  • lower: 138 functions in 1048 ms
  • codegen: 2247093 chars of Rust in 893 ms

The natively compiled compiler (patc1) runs the same front end roughly two orders of magnitude faster; rustc then dominates end-to-end compile time.
