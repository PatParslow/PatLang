The compiler, measured on itself

The self-hosted compiler front+middle end processing its own complete source (668274 chars), run under the Stage 0 interpreter while building this page:

  • tokenize: 95020 tokens in 1100 ms
  • parse: 178 top-level statements in 1284 ms

The natively compiled compiler (patc1) runs the same front end roughly two orders of magnitude faster; rustc then dominates end-to-end compile time.
