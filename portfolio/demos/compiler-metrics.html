The compiler, measured on itself

The self-hosted compiler front+middle end processing its own complete source (383016 chars), run under the Stage 0 interpreter while building this page:

  • tokenize: 62601 tokens in 9610 ms
  • parse: 119 top-level statements in 2373 ms
  • lower: 117 functions in 20589 ms
  • codegen: 1923951 chars of Rust in 11168 ms

The natively compiled compiler (patc1) runs the same front end roughly two orders of magnitude faster; rustc then dominates end-to-end compile time.
