The compiler, measured on itself

The self-hosted compiler front+middle end processing its own complete source (643294 chars), run under the Stage 0 interpreter while building this page:

  • tokenize: 91266 tokens in 20725 ms
  • parse: 176 top-level statements in 570 ms
  • lower: 174 functions in 517 ms
  • codegen: 3152377 chars of Rust in 488 ms

The natively compiled compiler (patc1) runs the same front end roughly two orders of magnitude faster; rustc then dominates end-to-end compile time.
