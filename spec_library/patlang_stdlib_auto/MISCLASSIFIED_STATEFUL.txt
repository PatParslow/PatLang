# Functions the risk classifier (patlang_function_discovery.patlang's
# body_looks_side_effecting) marked "likely_pure" and the auto-prober
# therefore probed and wrote a spec for -- but which are NOT actually
# pure/reproducible. Found via a statistically-sampled fresh-execution
# spot-check (30/430 new specs re-executed and compared byte-for-byte
# against their recorded observed_output): 2 of 30 (6.7%) came back
# DIFFERENT on a fresh call with the identical input.
#
# Root cause, confirmed by reading the actual bodies: both delegate
# real file-backed persistent state (regression weights, read via
# load_regression_weights/load_task_regression_weights, written via
# save_regression_weights/save_task_regression_weights) to a HELPER
# function, rather than touching write_file/read_file directly in
# their OWN body text. The risk classifier only scans a candidate's
# own body-window text for risky substrings -- it has NO transitive
# call-graph awareness, so a function that delegates its actual I/O to
# a helper is invisible to it even though its real, observed behaviour
# is neither pure nor stable across repeated identical calls.
#
# Swept the rest of the 616-entry auto-probed set for the SAME known
# helper names (load_ir/save_ir/load_regression_weights/
# save_regression_weights/load_task_regression_weights/
# save_task_regression_weights, the only load_*/save_* functions
# anywhere in the codebase) and found 4 more direct hits beyond the 2
# the random sample caught -- removed all 6 total, listed below.
# load_ir/save_ir (self_hosting/lib/ir_io.patlang) are never actually
# called anywhere in the codebase (confirmed via grep) so pose no risk.
#
# This is a real, useful finding about the DISCOVERY pipeline, not the
# spec-library data itself -- see spec_library/NEEDS_ATTENTION.md for
# the full writeup and the suggested classifier fix (transitive
# same-file helper-call awareness, or at minimum a name-pattern check
# for load_*/save_*/persist_*/history_* helpers).

friendly_cli__lib__perf_database__update_task_weights (calls save_task_regression_weights -- writes persisted regression weights; caught by the random spot-check sample itself)
friendly_cli__lib__adaptive_predictor__predict_compile_duration (calls load_regression_weights -- reads externally-mutable persisted state; caught by the random spot-check sample itself)
friendly_cli__lib__adaptive_predictor__load_regression_weights (IS the read accessor itself -- found via the full sweep, not the random sample)
friendly_cli__lib__adaptive_predictor__update_model_weights (calls both load_regression_weights and save_regression_weights -- found via the full sweep)
friendly_cli__lib__perf_database__load_task_regression_weights (IS the read accessor itself -- found via the full sweep)
friendly_cli__lib__perf_database__predict_task_duration (calls load_task_regression_weights -- found via the full sweep)
